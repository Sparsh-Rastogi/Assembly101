## 1. Overview of the 8051 (Slides 2, 5)

- 8-bit microcontroller: **8-bit ALU, 8-bit data bus (external), 16-bit address bus (external)**.
- On-chip blocks (Slide 2): **CPU, 4 KB ROM, 128 byte RAM, 2 Timers (Timer 0 & Timer 1) with counter inputs, Interrupt control (2 external interrupts), Serial port (TXD/RXD), 4 I/O ports (P0–P3), Bus control, Oscillator (OSC)**.
- Architecture (Slide 5, Fig 2.3) contains: **PC, DPTR, Memory Address Register (uses P0 and P2), Instruction Register, Instruction decoder/control logic, Accumulator (ACC), B register, two Temporary registers, 8-bit ALU, PSW flags, Internal RAM (general registers, stack, bit-addressable area, SFRs)**.
- Control lines: **RD, WR, PSEN, ALE** etc.
- Port 0 and Port 2 act as the external address/data bus: **P0 = low address (A0–A7) multiplexed with data (AD0–AD7); P2 = high address (A8–A15)**.

## 3. Internal RAM and Register Banks (Slides 6, 7)

**Internal RAM map (Slide 7, Fig 2.4):**

| Address | Content |
|---|---|
| 00h–07h | Register Bank 0 (R0–R7) |
| 08h–0Fh | Register Bank 1 (R0–R7) |
| 10h–17h | Register Bank 2 (R0–R7) |
| 18h–1Fh | Register Bank 3 (R0–R7) |
| 20h–2Fh | **Bit-addressable area**: bits 00h–7Fh (16 bytes × 8 = 128 bits; slide shows Bits 00–3F and 40–7F) |
| 30h–7Fh | **General user RAM and stack space** (80 bytes) |
| 80h–FFh | **Special Function Registers (SFRs)** |

- 4 banks × 8 registers = 32 bytes. Only **one bank is active at a time**, chosen by the RS1/RS0 bits of PSW (Slide 9).
- Default after reset: Bank 0.

## 5. Program Status Word – PSW (Slide 9)

- Located at **D0h**, **bit-addressable**, reset value = **00h**.
- Holds status bits reflecting the current state of the CPU; the ALU changes some bits automatically.

| Bit | Name | Meaning |
|---|---|---|
| 7 | **CY** | Carry flag |
| 6 | **AC** | Auxiliary carry |
| 5 | **F0** | User-definable flag |
| 4 | **RS1** | Register bank select bit |
| 3 | **RS0** | Register bank select bit |
| 2 | **OV** | Overflow flag |
| 1 | – | Reserved / user-definable |
| 0 | **P** | Parity flag (set by hardware by parity of ACC) |

**Register bank selection:**

| RS1 | RS0 | Bank | RAM space |
|---|---|---|---|
| 0 | 0 | Bank 0 | 00h–07h |
| 0 | 1 | Bank 1 | 08h–0Fh |
| 1 | 0 | Bank 2 | 10h–17h |
| 1 | 1 | Bank 3 | 18h–1Fh |

> Note: the slide's table labels the second column "RS2" – this is a typo; it should be **RS0**.

## 6. DPTR – Data Pointer (Slide 10)

- **16-bit register** = **DPH (high byte, 83h) + DPL (low byte, 82h)**.
- Used to hold a 16-bit address (e.g., external memory access, look-up tables).
- Both DPH and DPL are 8-bit registers, reset value 00h; each can be accessed separately.

## 7. Basic 8051 Circuit – Power, Reset, Clock (Slide 11)

**Circuit components (left → right):**
1. **220 V AC mains** → **step-down transformer** giving **6–12 V AC**.
2. **Bridge rectifier** (4 diodes) → full-wave rectified DC.
3. **100 µF** filter capacitor smooths the rectified output.
4. **LM7805** voltage regulator → regulated **+5 V**.
5. **10 µF** (output) and **100 nF** (decoupling/bypass) capacitors on the 5 V rail → VCC.
6. **Reset circuit:** push-button between VCC and RST pin, with a **10 kΩ resistor from RST to GND** (pull-down). Pressing the switch applies a logic HIGH to RST → resets the MCU. (8051 reset is **active-high**.)
7. **Clock circuit:** **crystal (4 MHz in this figure)** across XTAL1/XTAL2 (OSC1/OSC2) with **two 20–30 pF capacitors** to ground.
8. GND pin connected to ground.

**Remember:** a minimum 8051 system = power supply + reset + crystal/oscillator (+ EA tied to VCC when using internal ROM).

## 8. ADC Interfacing – ADC0804 (Slides 12, 13)

### 8.1 ADC0804 basics (Slide 12)
- Converts a **continuous-time analog input** to an equivalent **N-bit digital output**; ADC0804 gives **8-bit** output (DB0 = LSB … DB7 = MSB).
- 20-pin IC. Pins: **1 CS, 2 RD, 3 WR, 4 CLK IN, 5 INTR, 6 VIN(+), 7 VIN(–), 8 AGND, 9 VREF/2, 10 DGND, 11–18 DB7–DB0, 19 CLK R, 20 V+ (VCC)/VREF**.
- **VIN:** analog input voltage; **DB7–DB0:** digital output.
- **RD/WR and clock synchronisation are required between the ADC chip and the microcontroller.**

### 8.2 Example circuit with AT89S51 (Slide 13)
| Connection | Detail |
|---|---|
| Analog input | **10 kΩ potentiometer (R10)** across 5 V/GND; wiper → **VIN(+) pin 6**; VIN(–) pin 7 and AGND pin 8 grounded |
| VREF/2 (pin 9) | **No connection** → default reference = Vcc = 5 V |
| ADC clock | **R9 = 10 kΩ** (pin 19 CLK R to pin 4 CLK IN) + **C1 = 150 pF** to ground → internal RC clock (f ≈ 1/(1.1 RC) ≈ 606 kHz) |
| Data lines | **D0–D7 → P1.0–P1.7** (D0 = LSB, D7 = MSB) |
| Control lines | **CS → P3.7, RD → P3.6, WR → P3.5, INTR → P3.4** |
| Output display | **8 LEDs (D1–D8) on Port 0 (P0.0–P0.7)** with **560 Ω** resistors (R1–R8) to +5 V |
| Crystal | **11.0592 MHz** with 2 × **33 pF** capacitors (pins 18, 19) |
| Reset | S1 push-button + **C4 = 10 µF** + **R11 = 8.2 kΩ** to GND, at pin 9 |
| Power | VCC pin 40 and EA pin 31 tied to +5 V; GND pin 20 |

**Working (typical sequence):** CS = 0 → pulse WR low-to-high to start conversion → wait for INTR to go low (end of conversion) → RD = 0 → read P1 (digital value) → send to P0 (LEDs).

**Useful formula:** Digital output = (VIN / VREF) × 256 (resolution: step size = 5 V / 256 ≈ 19.5 mV when VREF = 5 V).

## 9. Motor Driver – ULN2003 (Slide 14)

- **Why needed:** a microcontroller port pin can supply only a **low current**; a **high-current device like a stepper motor** needs a driver IC to interface.
- **ULN2003** is an example of a motor driver IC:
  - **7 channels** (7 inputs, 7 outputs: IN1–IN7 → OUT1–OUT7).
  - Each channel has separate **BJT-based current amplification**.
  - Each channel is a **composite BJT (Darlington pair)** circuit → drives **large output current**.
  - Pin 8 = GND; **pin 9 = COM (common free-wheeling diodes)**.
  - Built-in **free-wheeling (clamp) diodes** protect against inductive back-EMF from motor coils.
  - Inputs are inverting buffers (shown with inverter symbols).

## 10. Stepper Motor Interfacing (Slide 15)

| Connection | Detail |
|---|---|
| 8051 → ULN2003 inputs | **P2.0 (pin 21) → IN1, P2.1 (pin 22) → IN2, P2.2 (pin 23) → IN3, P2.3 (pin 24) → IN4** |
| ULN2003 → Motor | **OUT1–OUT4 (pins 16, 15, 14, 13)** → four stepper motor coils |
| Motor common wire | Connected to **+5 V**, which is also tied to **COM (pin 9)** of ULN2003 |
| ULN2003 GND | Pin 8 to ground |
| 8051 supply | VCC pin 40 = +5 V, GND pin 20 |
| Reset | **10 µF capacitor + 10 kΩ resistor** with a reset switch at RST (pin 9) |

**Working:** the program sends a sequence of bit patterns to Port 2 (P2.0–P2.3); each pattern energises a coil, stepping the shaft. Delay between patterns sets speed; sequence order sets direction. *(Supplementary: a common full-step sequence is 0Ch, 06h, 03h, 09h.)*

## 12. Quick Revision Points

- 8051: **8-bit**, **40-pin**, **4 KB ROM**, **128 B RAM**, **2 timers**, **4 ports (32 I/O lines)**, **1 serial port**, **2 external interrupts (INT0, INT1)**.
- External address space: **16-bit → 64 KB**.
- **P0** = AD0–AD7; **P2** = A8–A15 (when external memory is used).
- Reset is **active-high** (RST pin 9).
- Register banks: 4 × 8; selected by **RS1:RS0** in PSW.
- Bit-addressable RAM: **20h–2Fh**.
- Stack and general RAM: **30h–7Fh**.
- SFR space: **80h–FFh**; PSW = **D0h**; ACC = **E0h**; B = **F0h**.
- ADC0804: 8-bit, needs CS/RD/WR/INTR handshaking and a clock.
- ULN2003: 7 Darlington channels with built-in free-wheeling diodes.
